Oauth Token ​

Request ​

  • HTTP Method: POST
  • Content Type: application/json
  • URL: [BASE_URL]/auth

Parameters ​

PropertyTypeRequiredDescriptionvalue
grant_typeStringtrueThe authorization grant typeclient_credentials
client_idStringtrueThe app id sended by mail
client_secretStringtrueThe app key generate from Simast Portal

Request example ​

js
axios.post('BASE_URL/auth',
      {
        grant_type: 'client_credentials',
        client_id: 'your-app-id',
        client_secret: 'your-app-secret'
      },
      {
          headers: {
            'Content-type': 'application/json',
          }
      }
)

Validation example ​

json
{
  "grant_type": {
    "type": "string",
    "enum": ["client_credentials"],
    "required": true
  },
  "client_id": {
    "type": "string",
    "required": true,
    "minLength": 1
  },
  "client_secret": {
    "type": "string",
    "required": true,
    "minLength": 1
  }
}

Response example ​

JSON
{
  "token_type": "Bearer",
  "expires_in": 86400,
  "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJSUzI1NiJ9..."
}

Error Response ​

JSON
{
  "error": "invalid_client",
  "error_description": "Client authentication failed"
}
